# Rastin RTL | راستین

افزونه‌ای برای بهبود نمایش متون فارسی و راست‌به‌چپ در Chrome و مرورگرهای مبتنی بر Chromium.

## امکانات

- فونت وزیرمتن، اصلاح جهت و فاصلهٔ متن، با حفظ چیدمان کد و فرمول‌ها.
- مسدودسازی تبلیغات، خط‌کش مطالعه و ابزارهای تمرکز.
- ترجمهٔ متن انتخاب‌شده و جست‌وجوی واژگان.
- هایلایت و یادداشت با ذخیرهٔ محلی، جست‌وجو و خروجی JSON یا چاپ.
- نوشتن و نقاشی روی صفحه، ذخیرهٔ طرح و خروجی PNG، SVG و JSON.

## نصب

### ویندوز — آماده‌سازی خودکار

در PowerShell اجرا کنید؛ Node.js و Git لازم نیست:

```powershell
irm https://raw.githubusercontent.com/Mancity1383/Rastin-RTL/main/install.ps1 | iex
```

فایل‌ها از شاخهٔ `main` دریافت و در `%LOCALAPPDATA%\Rastin-RTL` آماده می‌شوند. مسیر پوشه نمایش داده می‌شود و در صورت امکان در کلیپ‌بورد کپی می‌شود؛ صفحهٔ افزونه‌های مرورگر نیز باز می‌شود.

برای تکمیل نصب:

1. در `chrome://extensions` یا `edge://extensions`، **Developer mode** را روشن کنید.
2. **Load unpacked** را بزنید و پوشهٔ آماده‌شده را انتخاب کنید.
3. پاپ‌آپ راستین را باز کنید و ابزارهای دلخواه را برای سایت فعال کنید.

این مرحلهٔ بارگذاری طبق [روش رسمی Chrome](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked) توسط کاربر انجام می‌شود. پوشهٔ نصب را حذف یا جابه‌جا نکنید.

### با Node.js و Git

```bash
npx --yes --package=github:Mancity1383/Rastin-RTL#main rastin-rtl
```

نصب‌کننده فایل‌ها را از بسته به یک پوشهٔ ثابت در حساب کاربر کپی می‌کند و مسیر آن را برای **Load unpacked** نشان می‌دهد. برای دیدن گزینه‌ها، در سورس پروژه `node bin/cli.js --help` را اجرا کنید.

### دستی

[ZIP پروژه](https://github.com/Mancity1383/Rastin-RTL/archive/refs/heads/main.zip) را دانلود و استخراج کنید. مراحل **Developer mode → Load unpacked** را انجام دهید و پوشه‌ای را انتخاب کنید که `manifest.json` داخل آن است. ساخت پروژه برای نصب افزونه لازم نیست.

## به‌روزرسانی

دستور نصب خودکار را دوباره اجرا کنید، سپس در صفحهٔ افزونه‌ها **Reload** را بزنید و صفحه‌های باز را تازه‌سازی کنید. مسیر نصب ثابت می‌ماند. اگر فایل‌های نسخهٔ جدید ناقص باشند، نسخهٔ قبلی جایگزین نمی‌شود.

برای نصب دستی، فایل‌های جدید را در همان پوشهٔ قبلی قرار دهید و **Reload** را بزنید.

## فایل‌های محلی و PDF

برای استفاده روی صفحه‌های محلی مانند `file:///C:/Users/.../article.html`:

1. در `chrome://extensions` (یا `edge://extensions`) جزئیات راستین را باز کنید.
2. گزینهٔ **Allow access to file URLs** را روشن کنید؛ این دسترسی طبق [مستندات Chrome](https://developer.chrome.com/docs/extensions/reference/api/extension#method-isAllowedFileSchemeAccess) باید توسط کاربر داده شود.
3. صفحهٔ محلی را تازه‌سازی کنید و در پاپ‌آپ راستین، **فعال‌سازی روی فایل‌های محلی** را روشن کنید.

تنظیمات ابزارها بین فایل‌های محلی مشترک است؛ هایلایت‌ها و طرح‌ها برای هر فایل جدا نگهداری می‌شوند. پاپ‌آپ وضعیت دسترسی و دکمهٔ بازکردن جزئیات افزونه را نمایش می‌دهد.

برای PDF، در پاپ‌آپ **باز کردن فایل در راستین** را بزنید. PDF بازشده در مرورگر در صورت دسترسی، مستقیم در نمایشگر راستین باز می‌شود؛ می‌توانید فایل دانلودشده را هم انتخاب کنید یا روی نمایشگر بکشید. انتخاب دستی فایل به مجوز **Allow access to file URLs** نیاز ندارد.

نمایشگر مستقیماً صفحات اصلی PDF را نمایش می‌دهد؛ نوشته‌ها، تصاویر، جدول‌ها و ستون‌ها به HTML بازچینی نمی‌شوند. از نوار ابزار **هایلایت، زیرخط، قلم، کادر، یادداشت و پاک‌کن** استفاده کنید. هایلایت ناحیه‌ای و قلم روی PDF اسکن‌شده هم کار می‌کنند و به OCR نیاز ندارند. اگر سند متن قابل انتخاب داشته باشد، ابزار **انتخاب** و سپس **هایلایت انتخاب** یا **زیرخط انتخاب** روی همان صفحه علامت می‌زند. این ابزارهای PDF مستقل از تنظیمات اصلاح متن وب‌سایت‌ها در دسترس‌اند.

در روش **هوشمند**، با کشیدن ماوس روی نوشته، کلمه‌ها بر اساس جای واقعی آن‌ها روی PDF انتخاب می‌شوند؛ این انتخاب، حروف جداگانهٔ فارسی و متن ترکیبی فارسی و انگلیسی را هم پوشش می‌دهد. دوبار کلیک یک واژه و سه‌بار کلیک یک خط را انتخاب می‌کند. ابزار **هایلایت** و **زیرخط** انتخاب متنی را پس از رهاکردن ماوس مستقیماً ثبت می‌کنند؛ با ابزار **انتخاب**، نوار کوچک کنار انتخاب برای هایلایت، زیرخط و کپی در دسترس است. روش **ناحیه** برای انتخاب تصویری آزاد و فایل‌های اسکن‌شده است.

علامت‌ها برای هر سند با شناسهٔ محتوای فایل جداگانه ذخیره می‌شوند و با زوم، چرخش یا بازشدن دوباره در جای خود باقی می‌مانند. پنل **علامت‌ها** برای رفتن به صفحه، ویرایش یادداشت و حذف علامت است؛ **برگرداندن / انجام دوباره** و میانبرهای `Ctrl+Z` / `Ctrl+Shift+Z` هم در دسترس‌اند. آخرین صفحه، زوم و چرخش نیز بازیابی می‌شود.

میانبرهای نمایشگر: `+` و `-` (با Shift هم کار می‌کنند) برای زوم، کلیدهای بالا/پایین و `Page Up/Down` برای صفحهٔ قبل/بعد، `Home/End` برای ابتدا/انتهای سند، `Ctrl+G` برای شمارهٔ صفحه، `Ctrl+O` برای بازکردن فایل، `Ctrl+S` برای دانلود PDF علامت‌گذاری‌شده، `Shift+R` برای چرخش و `F` برای تمام‌صفحه. راهنمای کامل با `F1` باز می‌شود. میانبرها با چیدمان فارسی کیبورد هم کار می‌کنند و هنگام نوشتن یادداشت، ویرایش عادی متن حفظ می‌شود.

فضای خواندن ارتفاع پنجره را پر می‌کند و پنل صفحات اسکرول جداگانه‌ای در لبهٔ بیرونی دارد. اطلاعات فایل و حذف نسخهٔ محلی در منوی **گزینه‌های سند** بالای نمایشگر، و راهنما در دکمهٔ **راهنمای ابزارها** قرار دارند. کلیک روی علامت، محل آن را در همان پنل PDF با حرکت نرم و نشانهٔ کوتاه نشان می‌دهد؛ با اسکرول یا کلیک کاربر، حرکت متوقف می‌شود. تنظیم کاهش حرکت سیستم نیز رعایت می‌شود.

با **دانلود PDF با علامت‌ها** یک کپی از PDF با annotationهای استاندارد ذخیره کنید؛ صفحات اصلی و متن قابل انتخاب آن حفظ می‌شوند. یادداشت‌های فارسی داخل فایل ذخیره می‌شوند و یادداشت‌های موجود در PDF نیز قابل خواندن‌اند. خروجی فایل‌های رمزگذاری‌شده پشتیبانی نمی‌شود؛ برای خروجی، نسخهٔ بدون رمز را باز کنید. علامت‌ها و یادداشت‌های نمایشگر در همین مرورگر قابل ویرایش‌اند.

صفحه‌های افزونهٔ دیگر با آدرس `chrome-extension://...` و نمایشگر PDF داخلی مرورگر اجازهٔ اجرای مستقیم ابزارهای راستین را نمی‌دهند. برای این صفحه‌ها از دکمهٔ **باز کردن فایل در راستین** استفاده کنید؛ محتوای افزونهٔ دیگر را باید دانلود و در راستین انتخاب کنید.

نمایشگر با [PDF.js](https://mozilla.github.io/pdf.js/) و [pdf-lib](https://pdf-lib.js.org/) بسته‌بندی‌شده، فایل انتخابی را محلی پردازش می‌کند. برای بازخوانی، حداکثر ۱۰ فایل با مجموع ۲۰۰ مگابایت در مرورگر نگه می‌دارد (هر فایل حداکثر ۱۰۰ مگابایت). دکمهٔ **حذف نسخهٔ ذخیره‌شدهٔ فایل** این نسخه را حذف می‌کند؛ علامت‌ها و یادداشت‌ها باقی می‌مانند. برای بازیابی آن‌ها می‌توانید همان فایل را دوباره انتخاب کنید.

## توسعه

برای توسعه و نصب وابستگی‌های PDF.js، Node.js نسخهٔ `22.13+` از شاخهٔ ۲۲ یا `24+`:

```bash
npm ci
npx playwright install chromium
npm test
npm run test:install
npm run test:settings
npm run lint
```

آزمون نصب ویندوز: `npm run test:install:windows`.

`npm run dev` محیط آزمایشی React را اجرا می‌کند؛ `npm run build` همین محیط را می‌سازد. فایل‌های افزونه در ریشهٔ پروژه قرار دارند.
